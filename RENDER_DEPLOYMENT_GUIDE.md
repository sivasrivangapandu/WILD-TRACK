# WildTrackAI Render Deployment Guide (FIXED)

## Overview

This guide provides step-by-step instructions to deploy WildTrackAI on Render with all fixes applied for the previous deployment failures.

## What Was Fixed

### Issue 1: GitHub Clone Failures
- **Problem**: `fatal: unable to access 'https://github.com/.../': Could not resolve host: github.com`
- **Fix**: Added explicit retry logic and better error handling in build scripts

### Issue 2: Missing Directories
- **Problem**: `builder.sh: line 51: cd: /opt/render/project/src: No such file or directory`
- **Fix**: Explicit directory creation in build commands

### Issue 3: Database Initialization Races
- **Problem**: Database might fail to initialize due to concurrent access
- **Fix**: Safe initialization with retry logic and timeouts

### Issue 4: Model Download Timeouts
- **Problem**: Model downloads timeout and fail
- **Fix**: Increased timeout to 600s with exponential backoff retry

### Issue 5: Startup Script Path Issues
- **Problem**: Build succeeds but startup fails silently
- **Fix**: Added initialization verification before starting server

## Prerequisites

1. **Render Account**: https://render.com (free tier available)
2. **GitHub Repository**: Your fork/copy of WildTrackAI
3. **API Keys** (optional for full features):
   - Google Gemini API key (for chat)

## Step 1: Prepare Your Repository

```bash
# Ensure all fixes are committed
git add -A
git commit -m "Deploy: Add Render deployment fixes"
git push origin main
```

Verify these files exist:
- `render.yaml` - Deployment blueprint (updated with fixes)
- `backend/render_init.py` - Initialization helper
- `backend/requirements.txt` - Dependencies
- `frontend/vite.config.js` - Frontend build config

## Step 2: Create Render Services

### Via Render Dashboard

1. **Go to**: https://dashboard.render.com
2. **Click**: "+ New" → "Web Service"
3. **Connect**: Select your GitHub repository
4. **Deploy Settings**:
   - Name: `wildtrack-backend`
   - Environment: Python 3.10
   - Build Command: (Read from `render.yaml`)
   - Start Command: (Read from `render.yaml`)
   - Select "Free" plan

5. **Create Service**: Click "Deploy"

### Create Frontend Service

1. **In Dashboard**: "+ New" → "Static Site"
2. **Connect**: Same repository
3. **Settings**:
   - Name: `wildtrack-frontend`
   - Build Command: `cd frontend && npm install && npm run build`
   - Publish Directory: `frontend/dist`
   - Environment: (Copy from render.yaml)

4. **Deploy**: Click "Deploy"

## Step 3: Set Environment Variables

### For Backend Service

In Render Dashboard → Backend Service → Environment:

```
PYTHON_VERSION=3.10
PYTHONUNBUFFERED=1
PYTHONDONTWRITEBYTECODE=1
WILDTRACK_SKIP_MODEL_LOAD=0
CORS_ORIGINS=https://wildtrack-frontend-<your-id>.onrender.com
JWT_SECRET=<auto-generated by Render>
GEMINI_API_KEY=<your-key>
NINJA_API_KEY=<your-key>
CLOUDINARY_URL=<your-url>
```

> **Note**: Render auto-generates `JWT_SECRET`. You can leave it as-is.

### For Frontend Service

```
VITE_API_URL=https://wildtrack-backend-<your-id>.onrender.com
NODE_ENV=production
```

## Step 5: Troubleshooting Deployment

### Build Fails with Network Errors

1. **Retry the build**: Dashboard → Manual Deploy → "Deploy latest commit"
2. **Clear cache**: Dashboard → Environment → Rebuild

### Models Not Downloading

1. Check logs for network errors
2. Verify GitHub Release files are public:
   - https://github.com/sivasrivangapandu/WILD-TRACK/releases/tag/v2.0-models
3. Models auto-download on startup - wait 5-10 minutes

### Database Issues

1. Check logs for SQLite errors
2. Verify `backend/wildtrack.db` exists
3. Run manual initialization:
   ```bash
   python -c "from database import init_db; init_db()"
   ```

### Frontend Shows Network Error

1. Verify backend URL in VITE_API_URL
2. Check CORS headers in backend logs
3. Verify backend is running (health check)

## Known Limitations (Free Tier)

1. **Cold Starts**: Services sleep after 15 min inactivity (~60s to wake up)
2. **Disk**: Ephemeral (lost on service restart)
3. **Database**: Use embedded SQLite or upgrade to Render Postgres
4. **Memory**: 512 MB (sufficient for WildTrackAI)
5. **Build Time**: 3-5 minutes per deploy
