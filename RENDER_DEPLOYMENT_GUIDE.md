## STEP 1: Connect GitHub Repository to Render

### Option A: Using render.yaml (Recommended)
1. Go to **https://dashboard.render.com**
2. Click **"New +"** → **"Blueprint"**
3. Select your **WILD-TRACK** GitHub repository
4. Render will auto-detect `render.yaml` and configure:
   - Backend service (FastAPI + Gunicorn)
   - Frontend service (React + Vite)
5. Click **"Deploy"**

### Option B: Manual Service Creation (If Option A doesn't work)

#### Backend Service:
1. Click **"New +"** → **"Web Service"**
2. Connect GitHub repo (WILD-TRACK)
3. Configure:
   - **Name**: `wildtrack-backend`
   - **Environment**: Python
   - **Build Command**: `cd backend && pip install -r requirements.txt`
   - **Start Command**: 
     ```bash
     cd backend
     gunicorn main:app \
       --workers 2 \
       --worker-class uvicorn.workers.UvicornWorker \
       --bind 0.0.0.0:$PORT \
       --timeout 120 \
       --graceful-timeout 120
     ```
   - **Plan**: Standard (or Free to test)
4. Add Environment Variables (see Step 2)
5. Deploy

#### Frontend Service:
1. Click **"New +"** → **"Static Site"**
2. Connect GitHub repo (WILD-TRACK)
3. Configure:
   - **Name**: `wildtrack-frontend`
   - **Build Command**: `cd frontend && npm install && npm run build`
   - **Publish Directory**: `frontend/dist`
4. Add Environment Variables:
   - `VITE_API_URL`: Set to your BACKEND service URL (see below)
5. Deploy

## TROUBLESHOOTING

### Backend won't start
- Check logs for `[WARN] No GEMINI_API_KEY found`
- Verify env var is set in Render dashboard
- Restart the service

### Frontend can't connect to backend
- Check `VITE_API_URL` is set correctly
- Check CORS_ORIGINS includes frontend URL
- Backend must be deployed first

### Image upload fails
- Gemini might be rate-limited (wait 60 sec)
- Check API key is valid
- Verify CLOUDINARY_URL for optional uploads

### Model not loading
- Normal on first start (takes 1-2 min)
- Check backend logs for TensorFlow initialization
- Health check will show when ready
